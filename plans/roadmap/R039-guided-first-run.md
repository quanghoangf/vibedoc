# R039: Guided first run
**Parent:** R002
**Status:** planned
**Order:** 70
**Tasks:** —

Take a new user from `npx vibedoc` in an empty or existing repo to a roadmap, a first epic and a first task in about 5 minutes, because the first session decides whether people stay.

**In scope:** detect an empty project and offer a guided path, connect the agent, generate the roadmap from existing docs, break down the first epic
**Out of scope:** hosted onboarding, accounts
**Done when:** a first-time user reaches a board with real tasks in one sitting without reading the README
