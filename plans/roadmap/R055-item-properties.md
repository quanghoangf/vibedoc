# R055: Item properties
**Parent:** R002
**Status:** in-progress
**Order:** 160
**Tasks:** T080, T081, T082, T083, T084, T085

Tasks, epics and docs carry the properties a team needs to run work (who is in charge, real dates, a Paused state, the project's own statuses) and people can edit them right where they are. Today there's no owner, due dates are typed by hand, and the statuses are fixed.

**In scope:** Owner/PIC (human or which agent); a Paused status; due dates filled in automatically and start/done dates recorded automatically; custom statuses per project; one shared panel for tasks, epics and docs; editing properties in place
**Out of scope:** assigning work to real teammates across machines (R034 Team mode); time tracking
**Done when:** a task that an agent claims shows the agent as owner and gets a due date without anyone typing it, and a user can pause it and rename a status from the board
