# R047: Memory browser
**Parent:** R002
**Status:** done
**Order:** 140
**Tasks:** T089, T090, T091, T092

People can see and fix what agents remember without opening files, so bad memory gets corrected before it misleads the next session. Today the Memory tab only displays MEMORY.md.

**In scope:** view the handoff and all knowledge entries; search and filter by type; edit, add and delete entries; see when each entry was last changed and by whom (human or agent)
**Out of scope:** graph view (R053); stale-memory warnings (R051)
**Done when:** a user finds a wrong entry through search, fixes or deletes it in the Memory tab, and the next agent session sees the change
