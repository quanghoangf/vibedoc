# R106: Portfolio overview
**Parent:** R002
**Status:** planned
**Order:** 470
**Tasks:** T548, T549

One page answers "how are all my projects doing?", so the user decides where to spend the day without opening each roadmap.

**In scope:** per project or group: epic progress, at-risk and overdue epics, tasks done this week by agents and by people, last activity; sort by attention needed; open the project's roadmap from a row
**Out of scope:** charts over long time ranges, time tracking, reports for stakeholders
**Done when:** the user sees which of their projects has an at-risk epic from one page

## Scenarios
### S1: At-risk first
- WHEN one project has an at-risk epic and the others don't
- THEN that project sorts first with the epic named
