# R077: Site analytics
**Parent:** R002
**Status:** planned
**Order:** 300
**Tasks:** —

We learn which parts of the site lead to installs, so the landing page and docs improve on evidence, without tracking people.

**In scope:** privacy-friendly counts of visits, install-command copies per channel, demo opens and GitHub clicks; a simple view of the numbers; no cookies or personal data
**Out of scope:** product telemetry inside the VibeDoc app, A/B testing
**Done when:** the site shows how many visitors copied each install command in the last 30 days
