# R060: Evidence report per task
**Parent:** R002
**Status:** done
**Order:** 200
**Tasks:** T153, T154, T155, T156

Each task gets one document that proves its feature works: what was tested, what it looked like, and whether it passed.

**In scope:** a markdown evidence doc per task (steps, expected result, pass/fail, embedded screenshots, link to the local video, run time and commit), regenerated on each run with history of past runs, opened from the task panel and the card badge
**Out of scope:** PDF/HTML export, comparing screenshots between runs
**Done when:** opening a done task shows its evidence doc with a screenshot and result for every automated checklist item
