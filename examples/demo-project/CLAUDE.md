# Listly — Agent Instructions

Listly is a small fictional to-do SaaS used as the VibeDoc demo project. Shared lists, reminders, and a mobile app later.

## Stack
- Next.js web app, Postgres with row-level security (ADR-001), SSE for live sync
- Times are stored in UTC (see E003)
